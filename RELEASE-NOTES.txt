Payment Tool - release notes

1.1.0 (2026-10-15)
- Narrow window no longer breaks labels into one word per line. Buttons, names and
  headings stay on one line, and the blocks reflow instead.
- The guide lays its four steps out two by two when the window is small.

1.0.9 (2026-10-15)
- Cleaner screen: one short line per step, and the log panel only shows up while
  something is running.
- The guide is now a picture of the flow instead of a page of text, and follows the
  light or dark setting of the tool.

1.0.8 (2026-10-15)
- Check result PDFs no longer carry the 'M-invoice Support' chat bubble in the corner.
  The widget was removed once but drew itself again before the page was printed.

1.0.7 (2026-10-15)
- The translate prompt is now turned off by the page itself. The Edge flag in 1.0.6
  did nothing when Edge was already running.

1.0.6 (2026-10-15)
- Edge no longer asks to translate the tool window on every start.

1.0.5 (2026-10-15)
- The open invoice list no longer folds back on its own: the table only redraws when
  something actually changed, and a list you opened stays open.

1.0.4 (2026-10-15)
- Invoice detail: click the invoice name to open its PDF, or 'kết quả' for the check result.
- Invoice detail scrolls sideways, so long seller names are no longer cut off.
- A tool window whose server has stopped now closes itself instead of staying open.

1.0.3 (2026-10-15)
- Update check reads the new version straight away instead of waiting a few minutes
  for the GitHub file cache to catch up.

1.0.2 (2026-10-15)
- Checking invoices no longer flashes a black console window.
- Invoice Check output now shows inside the tool, with a live progress bar row
  while it checks and exports.

1.0.1 (2026-10-15)
- Guide tab was blank: the page never loaded the guide into its frame.
- Invoice detail lines: amounts are grouped by thousands and line up in a column.

1.0.0 (2026-10-15)
- New window-based interface. No more typing numbers in a black console.
- One screen lists every person in data, with invoice / PDF / check / to trinh counts
  and a status badge. Tick the people you want, then press a step.
- Step 1 Check invoices, step 2 Fill on the portal, step 3 Move saved people to done.
- Filling now handles the portal login by itself: if the session is gone it opens the
  login page, waits for you, and carries on without asking.
- Built-in Update tab: it reads the latest version from GitHub and installs it,
  or installs from a local zip when the machine cannot reach GitHub.
- Dropped the two steps nobody used: copy invoices from OneDrive, and build the
  request file as a separate step (filling rebuilds it anyway).
