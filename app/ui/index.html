Nhập đơn đề nghị thanh toán

Bước 1

Kiểm tra hóa đơn

Chạy Invoice Check cho hóa đơn chưa có kết quả, lưu PDF vào thư mục check của từng người.

Bước 2

Điền đơn lên cổng

Tự tạo file đơn, điền trường, import XML, đính tờ trình và file check, sửa từng dòng hóa đơn. Chưa đăng nhập thì tool mở sẵn cổng để đăng nhập rồi tự chạy tiếp. Dừng trước nút Lưu.

Bước 3

Chuyển sang done

Người đã bấm Lưu trên cổng thì chuyển thư mục của họ sang done theo tháng, để đợt sau không nộp trùng.
